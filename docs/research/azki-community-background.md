# ファン文化とホロライブ外との交流

本文の根拠は本人の公開投稿・配信と公式資料。紹介記事や非公式wikiは元資料を探す手がかりにだけ使った。

## 開拓者の名前

- [2018年11月15日の本人投稿](https://x.com/AZKi_VDiVA/status/1063061721579839488)に「私と一緒に世界を創ってくれるファンのみんなは #開拓者」とある。
- X本文は公式の `publish.twitter.com/oembed` が返す埋め込みHTMLでも確認した。GeoGuessrを始めてから付いた名前とは扱わない。
- 「世界を一緒に創り、切り開く」という意味を要約し、参加条件やファン歴についての推測は加えない。

## 開拓者のビジュアル

- [2023年5月14日23:51 JSTの本人投稿](https://x.com/AZKi_VDiVA/status/1657760488783233024)と添付画像を確認した。本文は公式の `publish.twitter.com/oembed` と `cdn.syndication.twimg.com/tweet-result`、画像は同レスポンスの `pbs.twimg.com/media/FwGLazVagAYoO3G.jpg` で確認した。
- 投稿には「ついに開拓者の姿が明らかに！！！こちらです！！！」とある。画像の表記は「開拓者」「カイタクシャ」「新種 UMA」「ゲッサー類」「ディーバ科」「AZKi 作」。ページのプロフィール表はこの表記を整理したもので、身長・体重・性別など画像にない設定は加えていない。
- 本文の結びは「現在の開拓者の姿が決まりました。」とし、本人投稿をX公式の `widgets.js` / `createTweet` で埋め込む。読み込めない場合は、短い引用とXへのリンクを表示する。プロフィール表は埋め込みの成否にかかわらず表示し、画像本体をリポジトリへ転載していない。
- [2023年5月14日のお絵描き配信](https://www.youtube.com/watch?v=RwU3iquAJQQ)。本人チャンネルのタイトル・公開日・概要欄を確認。概要欄には初のお絵描き配信で視聴者の案を募集するとある。
- 日本語の公開自動字幕で、3:27〜に以前の歌枠・雑談で姿の案を相談していた話、3:49〜にモグラ・ツチノコ・ビーバーの案、4:16〜にチャットの案を取り入れる方針を確認。
- 5:43〜にはファンマークがハンマーとツルハシであること、43分台〜にはピンクの色選び、55:50〜にはアホ毛、85:02〜にはビーバーを出発点にした架空の新種の生き物である説明がある。
- この配信でマスコットの姿がまとまった経緯を説明する。後日の商品化・モデル制作の日付や担当者は、今回調べた資料だけから確定しない。
- 自動字幕の誤変換を考慮し、長い逐語引用は避けた。音声を直接聴いての照合、動画・音声本体の取得は行っていない。
